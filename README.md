# 🌸 Маммалыш — Сайт-визитка магазина для беременных и кормящих мам

Уютный, минималистичный и адаптивный сайт-визитка с адресом, телефоном, графиком работы и ссылками на социальные сети (**Instagram**, **VK**, **MAX**).

---

## 🚀 Как бесплатно запустить сайт на GitHub Pages

Сайт полностью подготовлен для работы на **бесплатном GitHub Pages**:
- В `vite.config.ts` настроен относительный базовый путь `base: './'`.
- В `.github/workflows/deploy.yml` добавлен автоматический GitHub Actions скрипт сборки и публикации.

### Инструкция по публикации:
1. Загрузите файлы этого проекта в ваш репозиторий на GitHub.
2. В репозитории на GitHub перейдите в **Settings** (Настройки) → **Pages** (слева в меню).
3. В разделе **Build and deployment**:
   - В выпадающем списке **Source** выберите **GitHub Actions**.
4. Всё готово! При каждом коммите в ветку `main` (или `master`) GitHub автоматически соберет сайт и опубликует его по адресу `https://<ваш_логин>.github.io/<название_репозитория>/`.

## 📝 Как изменить контакты магазина

Все данные магазина собраны в одном файле:
👉 **`src/storeConfig.ts`**

Внутри него на русском языке расписаны все поля:
- **Телефон**: `phone.display` (текст) и `phone.raw` (для набора).
- **Адрес**: `address.city`, `address.street`, `address.landmark`, ссылки на Яндекс.Карты и 2ГИС.
- **График работы**: `schedule.details` (часы работы по дням недели).
- **Социальные сети**: `socialLinks.instagram`, `socialLinks.vk`, `socialLinks.max`.
- **Цвета сайта**: `#3CB3E5` (небесно-голубой) и `#E86B9A` (нежно-розовый).
